## 1. 项目简介

**ScholarQuant** 是一个专为大学生设计的金融数学建模与可视化工具。它旨在解决“在有限的大学四年里，如何平衡投资波动与生活开销”这一核心难题。

通过输入初始资产（黄金/纳指/稳健理财）、定投策略以及精细的学制与消费模型，系统能够计算出**“在校月均可支配生活费”**，并基于实时行情与历史数据（牛/熊/均值）进行压力测试，帮助学生规避现金流断裂的风险。

## 2. 技术栈架构

本项目采用高性能的前后端分离架构：

- **前端 (Frontend)**:
  - **核心框架**: `Vue 3` (Composition API)
  - **构建工具**: `Vite` (极速冷启动)
  - **UI 组件库**: `Naive UI` (不仅美观，且拥有强大的 `InputNumber` 和 `DatePicker` 组件，非常适合金融表单场景)
- **后端 (Backend)**:
  - **核心框架**: `FastAPI` (Python 异步框架，适合处理金融计算密集型任务)
  - **数据处理**: `Pandas` / `NumPy` (用于时间序列处理与定投逻辑向量化计算)

## 3. 核心功能模块

系统允许用户对以下参数进行灵活配置与微调：

### 💰 资产与定投配置

- **初始资金录入**：支持修改在 **黄金 ETF**、**纳斯达克 ETF** 以及 **稳健理财** 中的初始投入金额。
- **智能定投计算**：
  - **纳指专属定投逻辑**：支持设定从黄金 ETF 每日/每周转移固定金额至纳斯达克 ETF。
  - **止盈/止投阈值**：设定纳指持仓上限（如 40,000 或 60,000），达标后自动停止定投。

### 📅 精细化时间与收支模型

- **时间跨度**：精确设定入学日期至毕业日期的完整时间轴。
- **假期管理**：
  - 自定义寒暑假时间段。
  - **“排除假期”开关**：开启后，计算“在校生活费”时将自动剔除假期月份（假设假期由家庭覆盖或低消费），使结果更贴近在校真实情况。
- **现金流管理**：
  - **固定收支**：输入每月固定花费（硬性支出）与固定收入（兼职/生活费）。
  - **弹性调节**：
    - **学费开关**：是否包含学费支出？具体金额多少？（支持按年自动扣除）。
    - **临时大额消费**：支持插入特定时间点的额外支出（如大三购买电脑、毕业旅行）。

### 📊 核心产出

- **可视化分析**：计算并展示在不同时期（大一至大四），每个**上学日**平均可支配的生活费金额。

## 5. 实时与历史分析

为了提供更具参考价值的决策依据，项目集成了以下高级功能：

### 🔗 实时市场追踪

- **联网分析**：系统可链接当前的基金市场数据，实时更新用户持仓（黄金/纳指）的最新市值与收益率。
- **长期追踪**：支持用户长期关注特定策略的表现，并根据实际情况进行微调（例如更换跟踪不同指数的 ETF，或添加临时的额外消费支出）。

### 📜 历史情景回测

系统链接了详尽的历史股市数据，将用户的当前模型代入不同历史时期进行复盘：

- **平均数据**：在市场表现平稳年份的资金留存情况。
- **熊市数据**：模拟如 2000年 或 2022年 暴跌行情下，生活费是否会断供。
- **牛市数据**：模拟如 2019-2021年 暴涨行情下，资产增值的上限。

通过可视化图表，直观展示在这些不同“平行宇宙”中，你的钱包厚度会如何变化。
